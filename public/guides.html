Installation guides

Choose an operating system and follow verified setup steps.

🐍 Python

1. Download the installer from python.org.

2. Important: Check the box Add Python to PATH during installation.

3. Verify by running: python --version

1. Open Terminal.

2. Run: brew install python

3. Verify: python3 --version

1. Open Terminal.

2. Run: sudo apt update && sudo apt install python3

3. Verify: python3 --version

🟢 Node.js

1. Download the Windows Installer from nodejs.org.

2. Run the installer and follow the prompts.

3. Verify: node -v and npm -v

1. Open Terminal.

2. Run: brew install node

3. Verify: node -v

1. Run: sudo apt update && sudo apt install nodejs npm

2. Verify: node -v

☕ Java (JDK)

1. Download the JDK from Adoptium.

2. Run the installer and set JAVA_HOME in Environment Variables.

3. Verify: java -version

1. Open Terminal.

2. Run: brew install openjdk

3. Verify: java -version

1. Run: sudo apt install openjdk-17-jdk

2. Verify: java -version

⚙️ C++ (GCC/Clang)

1. Install MinGW or Visual Studio Community with C++ workload.

2. Add the bin folder to your System PATH.

3. Verify: g++ --version

1. Open Terminal.

2. Run: xcode-select --install

3. Verify: clang++ --version

1. Run: sudo apt install build-essential

2. Verify: g++ --version
